# SwiftProof v0.1.0

First public release of SwiftProof, a Go CLI that helps developers focus their
review of AI-assisted pull requests on changes that need human judgment.

## Included

- Immutable Git comparison and deterministic risk signals, with Go AST analysis.
- Markdown and JSON reports with a focused review plan and traceable evidence.
- Optional AI reviewer using a compatible Chat Completions endpoint.
- Isolated Docker checks and differential Go tests for reproducible evidence.
- Portable Windows, Linux and macOS archives for amd64 and arm64, with SHA-256 checksums.

## Installation

Download the archive for your operating system and architecture, verify its
entry in `SHA256SUMS`, extract it, and put `swiftproof` (`swiftproof.exe` on
Windows) on your PATH. Run `swiftproof version` to verify installation.

Git is required. Docker with Linux containers and a preloaded toolchain image
is required only for executing repository checks. Go is not required to run
the downloaded CLI.

## Current limits

This is an initial 0.x release. Review signals and passing tests are not a
correctness guarantee and do not automatically approve or merge pull requests.
Architecture signals do not yet constitute a complete semantic drift model.
Snapshots reject repository symlinks and submodules. There is no automatic
dependency installation or global call graph; semantic analysis focuses on Go.
Archives are not signed or notarized. See README.md and SECURITY.md for setup
and execution boundaries.
